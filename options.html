Cookie Auditor Pro

Configuration and privacy controls

Domain allowlist

One base domain per line. Example: cdac.in includes its subdomains. Only domains also granted in manifest.json can be scanned.

Test-cookie value prefix

Only non-excluded cookie names beginning with this prefix have their values retained. Use a prefix reserved for disposable test cookies, such as audit_.

Excluded cookie names

One exact cookie name per line. Exclusions take priority over the test prefix and remove matching cookies from inventory, event history and value snapshots.

Audit Reporting (Optional)

Send audit data to a server for security monitoring. Configure what gets saved locally vs. sent to email below.

Email Report Configuration

Choose what data gets sent in email reports. All data is always saved locally regardless of these settings.










⚠️ Security Note:
  • Local Storage: ALL cookie data (including values) is ALWAYS saved locally for your analysis
  • Email Reports: Only selected data above will be sent to email
  • Recommendation: Keep "Include cookie VALUES" unchecked to avoid sending sensitive data via email

Important permission note

For a new base domain outside the currently granted cdac.in scope, update host_permissions in manifest.json, then reload the unpacked extension at chrome://extensions. Do not use broad all-sites permissions.

Settings are stored in this Chrome profile's local extension storage. They are not synchronized between computers.
